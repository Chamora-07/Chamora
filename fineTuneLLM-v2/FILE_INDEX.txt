                        QUICK REFERENCE
================================================================================

WHAT DOES IT DO?
  Takes ML model output → Analyzes metrics → Produces root cause + confidence via LLM

INPUTS:
  - id, application_id, config_id, window_timestamp
  - ml_severity, ml_root_cause
  - evidence (JSON with 13+ metrics)

OUTPUTS:
  - root_cause (MEMORY_LEAK, CPU_SATURATION, etc.)
  - confidence (0.0-1.0 score)
  - affected_component (API_SERVER, DATABASE, etc.)
  - evidence (explanation with metrics)
  - analysis_reasoning (detailed analysis)

PERFORMANCE:
  - LLM (Qwen): 2-5s/record, 200-500 records/min (faster with GPU)

REQUIREMENTS:
  - Python 3.8+
  - pandas, numpy, requests
  - Mandatory: Ollama + Qwen 4B model for LLM
